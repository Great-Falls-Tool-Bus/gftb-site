# Great Falls Tool Bus: paths that stay off upstream.
#
# Agent tooling lives on contributor forks, named <repo>-contrib, on the
# agents-overlay branch. It never lands on an organization branch or in a pull
# request into one. The rule is CONTRIBUTING.md, section "Agents":
# https://github.com/Great-Falls-Tool-Bus/.github/blob/main/CONTRIBUTING.md
#
# The rule covers directives, skills, prompts, plugins and notes, and scripts
# and receipts that exist to drive agent sessions. The entries below are the
# enforced set.
#
# Canonical copy: meta steering/githooks/. Mirror: the organization .github
# repository, githooks/. Repositories vendor it in .githooks/ with the hooks.
# The pre-push hook reads it for pushes to an organization remote. In meta,
# `just upstream-tooling-audit` reads the copy on meta's default branch.
#
# Syntax, one entry per line:
#   deny PATTERN                       a path that must not be upstream
#   deny REPO:PATTERN                  the same, for one repository only
#   allow REPO:PATH TICKET REASON      one exact path admitted on purpose
#
# A PATTERN is anchored at the repository root and matched without regard to
# case. `*` and `?` stay inside one path segment. A leading `**/` lets the rest
# start at any depth. A trailing `/` matches the bare name, file or symbolic
# link, and everything below it. Matching is by path, never by a word inside a
# path or a file. Hooks, Huskycat, CI and product files are never listed: no
# pattern matches their ordinary files. An allow entry is the only exception,
# and it names one exact path, a ticket and a reason.
